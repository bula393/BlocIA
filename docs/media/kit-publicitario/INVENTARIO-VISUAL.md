## Uso responsable del material

- Mantener intacto el texto y la geometría de las capturas; recortar o mover la captura completa en edición.
- Las preguntas, respuestas y conversaciones incluidas son datos de demostración. No son testimonios ni promesas de respuesta idéntica.
- No reutilizar logos, tipografías, música ni cuadros de campañas de terceros. Las campañas citadas en [HERRAMIENTAS-IA.md](HERRAMIENTAS-IA.md) orientan el enfoque; este kit contiene recursos de BloqIA.
- Si se genera una persona/avatar con IA, no atribuirle una experiencia real con la app.
