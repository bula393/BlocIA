# Kit publicitario de BloqIA

Material para planificar piezas de marca y producto. Se armó el 17 de octubre de 2026 con capturas de la app y referencias de los videos ya producidos.

## Archivos

- [PROMPTS.md](PROMPTS.md): brief general y tres prompts listos para adaptar a un generador de video.
- [HERRAMIENTAS-IA.md](HERRAMIENTAS-IA.md): herramientas actuales, qué aporta cada una y flujo recomendado.
- [INVENTARIO-VISUAL.md](INVENTARIO-VISUAL.md): índice de capturas y referencias incluidas.
- `capturas-app/`: nueve capturas reales de la interfaz móvil de BloqIA.
- `referencias-campana/`: hojas de escenas de las tres piezas previas; sirven para continuidad visual y ritmo.

## Idea de producción

Usar las capturas reales para explicar la interfaz y generar con IA solo planos de contexto o atmósfera. Añadir textos, marca y movimientos de UI en edición para que queden fieles y legibles. El selector, las conversaciones de ejemplo y las respuestas deben identificarse como demostración cuando se muestren fuera de contexto.

Las capturas muestran datos de ejemplo. No son testimonios ni garantizan una respuesta idéntica en producción. Las piezas anteriores y su investigación están en [docs/media/CAMPANA.md](../CAMPANA.md).
