# Story Acceptance Evidence

## US1 Login de usuario

- Backend validates successful login, invalid login, repeated failures without lockout, and Google auth contract.
- Frontend renders login and Google action.
- E2E login page loads.

## US2 Registro de cuenta

- Backend validates normal registration, duplicate mail, weak password rejection, and Google completion.
- Frontend renders register form and password feedback.

## US3 Gestion de perfil

- Backend validates profile read/update and invalid value rejection.
- Frontend renders profile fields and edit controls.

## US4 Perfil tecnico de IA

- Backend validates provider listing, token save/replacement/removal, masking, and ownership isolation.
- Frontend renders technical profile area and provider token controls.

All story evidence is linked from the per-story curl evidence files and test summaries.
